Éditeur de flotte

Édite le JSON de flotte commun à tous les outils (profil de vol, distance pélicandrome, comparatif, plans d'eau). Chaque grandeur porte un statut de source (trouvée : constructeur / publiée — ou interprétée : estimée / interpolée / analogie / concept) et un commentaire libre : lien de la source, ou base de l'interpolation. Rien n'est définitif tant que le JSON n'a pas été réexporté puis remis à la place de l'ancien.

Édition

Statut de source : constructeur ou publiée = donnée trouvée ; estimée, interpolée, analogie, concept = donnée interprétée (affichée avec un astérisque dans les outils). Le commentaire attend le lien de la source, ou la base de l'interpolation. Cette fenêtre ne se ferme que par Annuler ou Valider.

Import d'une fiche d'appareil

Chaque ligne est un désaccord entre le référentiel et le fichier importé. Les champs identiques ne sont pas listés. Rien n'est appliqué sans votre choix : cochez, colonne par colonne, la valeur qui fait foi. Le statut de source et le commentaire de chaque côté vous disent d'où sort le chiffre. Cette fenêtre ne se ferme que par Annuler ou Valider.
