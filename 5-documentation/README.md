## Le manuel technique

**[PROJET-reference.md](PROJET-reference.md)** est le manuel historique du
projet. Il ne s'adresse pas à l'utilisateur mais à qui veut **modifier** les
outils : conventions de code, blocs de données embarquées, décisions datées,
journal de travail.

C'est le document qu'un agent IA reprenant le projet doit lire en premier.

---

## Si vous ne deviez lire qu'une chose

[12 — Conventions et limites](12-conventions-et-limites.md).

Les chiffres de ce dépôt sont presque tous des **bornes hautes de candidats** :
ce qui serait possible si rien d'autre ne s'y opposait. Ni la profondeur, ni les
ponts, ni le marnage estival ne sont pris en compte. Le savoir change la façon
dont on lit une carte.
